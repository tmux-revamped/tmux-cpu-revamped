$ cpu-revamped help
cpu-revamped - load, temperature and clock in the status bar

usage:
  cpu-revamped apply          bind the key and fill the placeholders
  cpu-revamped list           print what apply would send to tmux
  cpu-revamped status NAME    print one placeholder: percentage, icon,
                              fg_color, bg_color, temp, temp_icon,
                              temp_fg_color, temp_bg_color, freq, load,
                              load5, load15, count, graph, top_process,
                              governor, load_color or alert
  cpu-revamped refresh        sample the CPU now for the status line
  cpu-revamped card           print every figure as a table
  cpu-revamped popup          open a CPU monitor in a tmux popup
  cpu-revamped daemon         publish the placeholders on every tick, for
                              the options render mode
  cpu-revamped doctor         check this machine
  cpu-revamped version        print the version
  cpu-revamped help           print this page

keys:
  --popup-key KEY             the prefix key for the monitor popup, or off
  --popup-width SIZE          the popup's width, such as 80%
  --popup-height SIZE         the popup's height, such as 60%
  --popup-command COMMAND     what the popup runs, default btop, htop or top

sampling:
  --interval SECONDS          how long a sample stays fresh
  --detail-interval SECONDS   how long the temperature, the clock, the load
                              average, the busiest process and the governor
                              stay fresh
  --throttle-when-detached 0|1
                              1 stops sampling while no client is attached
  --render MODE               jobs or options
  --graph-width COUNT         samples kept for the graph

tiers:
  --medium-thresh PERCENT     where the medium load tier starts
  --high-thresh PERCENT       where the high load tier starts
  --TIER-icon TEXT            what #{cpu_icon} prints in the low, medium
                              or high tier
  --TIER-fg-color STYLE       what #{cpu_fg_color} prints in each tier
  --TIER-bg-color STYLE       what #{cpu_bg_color} prints in each tier
  --temp-medium-thresh DEGREES
                              where the medium temperature tier starts
  --temp-high-thresh DEGREES  where the high temperature tier starts
  --temp-TIER-icon TEXT       what #{cpu_temp_icon} prints in each tier
  --temp-TIER-fg-color STYLE  what #{cpu_temp_fg_color} prints in each tier
  --temp-TIER-bg-color STYLE  what #{cpu_temp_bg_color} prints in each tier
  --load-medium-ratio RATIO   load average per core that turns
                              #{cpu_load_color} medium
  --load-high-ratio RATIO     load average per core that turns it high
  --alert-icon TEXT           what #{cpu_alert} prints while the load or
                              the temperature is high

formats:
  --percentage-format FORMAT  printf format of the load percent
  --temp-format FORMAT        printf format of the temperature
  --temp-unit C|F             the unit of the temperature
  --freq-format FORMAT        printf format of the clock in megahertz
  --load-format FORMAT        printf format of the three load averages
  --icons SET                 ascii, or nerd for a Nerd Font glyph before
                              every metric
  --METRIC-label TEXT         the label before one metric
  --fixed-width on|off        on pads every figure to its natural width
  --METRIC-width COUNT        the width of one metric

output:
  --json                      list prints one JSON object
  --theme NAME                the look: kodougu, catppuccin-mocha,
                              catppuccin-latte, dracula, nord, gruvbox,
                              tokyo-night or mono

environment:
  CPU_REVAMPED_<SETTING>   the same as the option of that name, such as
                           CPU_REVAMPED_INTERVAL for --interval
  CPU_REVAMPED_THEME       the look, when --theme is not given
  CPU_REVAMPED_ACCENT      a colour such as #CBA6F7 for the accent
  KODOUGU_THEME            the family look, when neither is given
  KODOUGU_ACCENT           the family accent, when the tool's is unset
  NO_COLOR                 turn colour off

tmux options:
  @cpu_revamped_popup_key           the monitor popup key (default M-c)
  @cpu_revamped_popup_width         width of the popup (default 80%)
  @cpu_revamped_popup_height        height of the popup (default 80%)
  @cpu_revamped_popup_command       what the popup runs (default btop,
                                    htop or top)
  @cpu_revamped_interval            seconds a sample stays fresh
                                    (default 5)
  @cpu_revamped_detail_interval     seconds the temperature, the clock, the
                                    load average, the busiest process and
                                    the governor stay fresh (default 60)
  @cpu_revamped_throttle_when_detached
                                    1 stops sampling while no client is
                                    attached (default 0)
  @cpu_revamped_render              jobs or options (default jobs)
  @cpu_revamped_graph_width         samples kept for the graph (default 20)
  @cpu_revamped_medium_thresh       percent that starts the medium tier
                                    (default 30)
  @cpu_revamped_high_thresh         percent that starts the high tier
                                    (default 80)
  @cpu_revamped_temp_medium_thresh  degrees that start the medium
                                    temperature tier (default 65)
  @cpu_revamped_temp_high_thresh    degrees that start the high
                                    temperature tier (default 80)
  @cpu_revamped_load_medium_ratio   load average per core that starts the
                                    medium load colour (default 0.7)
  @cpu_revamped_load_high_ratio     load average per core that starts the
                                    high load colour (default 1.0)
  @cpu_revamped_<tier>_icon         icon of the low, medium or high tier
                                    (default one, two or three bars)
  @cpu_revamped_<tier>_fg_color     style of #{cpu_fg_color} in each tier
                                    (default none)
  @cpu_revamped_<tier>_bg_color     style of #{cpu_bg_color} in each tier
                                    (default none)
  @cpu_revamped_temp_<tier>_icon    icon of #{cpu_temp_icon} (default none)
  @cpu_revamped_temp_<tier>_fg_color
                                    style of #{cpu_temp_fg_color}
                                    (default none)
  @cpu_revamped_temp_<tier>_bg_color
                                    style of #{cpu_temp_bg_color}
                                    (default none)
  @cpu_revamped_alert_icon          text of #{cpu_alert} (default !)
  @cpu_revamped_temp_unit           C or F (default C)
  @cpu_revamped_percentage_format   format of #{cpu_percentage}
                                    (default "%s%%")
  @cpu_revamped_temp_format         format of #{cpu_temp}
                                    (default "%s" and the degree sign
                                    and the unit)
  @cpu_revamped_freq_format         format of #{cpu_freq}
                                    (default "%sMHz")
  @cpu_revamped_load_format         format of #{cpu_load}, #{cpu_load5}
                                    and #{cpu_load15} (default "%s")
  @cpu_revamped_icons               ascii or nerd (default ascii)
  @cpu_revamped_fixed_width         on or off (default off)
  @cpu_revamped_<metric>_label      label before one metric (default none)
  @cpu_revamped_<metric>_width      width of one metric (default none)
  @revamped_theme                   the family look (default kodougu)

notes:
  A metric that takes a label and a width is percentage, temp, freq, load,
  load5, load15, count, graph, top_process or governor, written with
  dashes in an option, such as --top-process-label. The graph width is
  also the number of samples the graph keeps.
  The placeholders are #{cpu_<name>} for each name status takes. Each
  prints the stored sample at once, and starts one background sample when
  it is older than the interval. The temperature, the clock, the load
  averages, the busiest process and the governor are read only for a
  placeholder the status line uses. With --render options each
  placeholder reads a tmux option that a background process fills on
  every tick, so a status refresh starts no process.

examples:
  cpu-revamped status percentage
  cpu-revamped card
  cpu-revamped --icons nerd --fixed-width on apply
  cpu-revamped list --json
exit 0
